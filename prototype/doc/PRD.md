### 技术

- js+css+html
- 动画：gsap
- 3D：three.js

### 设计原则

1. **留白即奢华** —— 信息密度低，元素间留白 ≥ 2× 行业默认
2. **少即是多** —— 每个屏幕只传达一个核心信息
3. **细节见品质** —— 微动效、微间距、字体细节决定品牌感
4. **科技与温度并存** —— 冷峻几何（科技感）+ 一抹品牌色（温度感）
5. **国际化通用** —— 双语切换下版式不破

### 色彩系统

#### 主色调

| 角色            | 色值                            | 用途            |
| --------------- | ------------------------------- | --------------- |
| 纯白（Canvas）  | `#FFFFFF` / `#FAFAFA`           | 主背景          |
| 浅灰（Surface） | `#F5F5F5` / `#EFEFEF`           | 卡片、分区背景  |
| 中灰（Divider） | `#E5E5E5`                       | 分割线、描边    |
| 文本主色（Ink） | `#0A0A0A` / `#1A1A1A`           | 标题、正文      |
| 文本副色        | `#6B6B6B` / `#8C8C8C`           | 次要说明        |
| **品牌主色**    | `#003B5C`（深海蓝） / `#0F4C81` | LOGO、CTA、强调 |

#### 品牌辅色（克制使用，单屏 ≤ 1 种）

| 名称   | 色值      | 用途                 |
| ------ | --------- | -------------------- |
| 静谧蓝 | `#4A6FA5` | 数据、信息           |
| 暖灰金 | `#B8924A` | 高端点缀、奖项       |
| 科技青 | `#00A3B4` | 智能玻璃、新能源板块 |
| 警示红 | `#C53030` | 错误、警告           |

#### 使用规则

- 黑白灰占比 ≥ **90%**，品牌色仅在 LOGO、CTA、关键数据出现
- 大面积色块不超过 3 处/屏
- 暗色模式（Dark Mode）本期**不做**（V1.5+ 评估）

### 栅格与版式

| 设备               | 栅格  | Gutter | 外边距   |
| ------------------ | ----- | ------ | -------- |
| 桌面（≥ 1280px）   | 12 列 | 24px   | 80-120px |
| 平板（768-1279px） | 8 列  | 20px   | 40-60px  |
| 手机（< 768px）    | 4 列  | 16px   | ≥ 20px   |

- **内容最大宽度：** 1440px（可放大至 1680px）
- **章节呼吸：** 每个 Section 垂直间距 ≥ 120px（桌面）/ 80px（移动）
- **段落节奏：** 信息块之间 32-48px
- **图文比例：** 图片占比 ≥ 50%，文字精炼
- **触控目标：** ≥ 44×44px

### 视觉元素

- **摄影 / 视频（核心）** —— 决定品牌高端感
  - 极简产品摄影（白底、高光、玻璃透明感）
  - 工厂 / 实验室极简空镜
  - 车与玻璃场景摄影（晨光、逆光）
- **图标** —— 线性，统一 2px 描边；推荐 Lucide / 自研
- **插画 / 3D** —— 克制使用，技术原理示意 / 制造工艺 / 数据可视化
- **装饰** —— 1px hairline 细分割线、大数字、极淡几何辅助线、玻璃光斑

### 动效与交互规范

#### 核心原则

- **慢而流畅：** 600-1000ms 缓动曲线
- **克制不炫技：** 服务于内容，不抢戏
- **统一节奏：** 全站动效时长 / 曲线统一

#### 推荐动效

- 入场：Fade + Y 位移（20-40px）—— **GSAP `fromTo`**
- 滚动叙事：parallax、pinning、reveal —— **GSAP + ScrollTrigger**
- 数字计数：进入视口后 0 → 目标值 —— **GSAP `to()`**
- Hover：图片轻微缩放、文字颜色渐变、按钮微光 —— **CSS `transition`**
- 页面切换：淡入淡出 + 加载条 —— **GSAP timeline**
- 微动画：Logo 加载、装饰线条生长 —— **GSAP DrawSVG（若需要）**

#### 技术栈（唯一指定）

| 用途                            | 工具                         | 备注                         |
| ------------------------------- | ---------------------------- | ---------------------------- |
| 滚动叙事                        | **GSAP + ScrollTrigger**     | 全站主力                     |
| 平滑滚动                        | **Lenis**                    | 与 ScrollTrigger 协同        |
| 2d平面全球地图 + 3d航道路线动画 | **Three.js（纯 ES Module）** | 渲染 SphereGeometry + Curve3 |
| 轻量插画                        | **Lottie**                   | 按需                         |
| 前端构建                        | **Vite**                     | ES Modules 原生支持          |
| 前端框架                        | **无**（纯原生 JS）          | 不引入 React / Vue / Next.js |
